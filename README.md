# Personal Projects

This is a simple React website created for practice purposes. The site acts as a basic hub to list and access personal projects.

The home page contains a header section titled **“Personal Projects”** with a hover effect. When the user scrolls down, a simple animation is triggered and a section displaying project names appears.

The project is intentionally kept minimal and is used to practice React fundamentals, basic animations, and component structure.

## Technologies Used

* React
* TypeScript
* Vite
* CSS

## Purpose

The main purpose of this project is to practice frontend development concepts such as layout design, hover effects, and scroll-based animations.
